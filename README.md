# やること ✅

スマホとPCで同期できる、自分用のタスク管理アプリ（PWA）です。

**URL: https://japanlocal.github.io/yarukoto/**

## 機能

- **今日 / 予定 / すべて / 完了** の4つの表示。期限切れは赤く目立たせる
- **すばやい追加**: `明日 15:00 レポート提出 !高` のように書くと期限・時刻・優先度を自動で設定
  - 日付: `今日` `明日` `明後日` `金曜` `来週月曜` `来週` `10/20` `10月20日`
  - 時刻: `15:00` `15時` `15時半`
  - 優先度: `!高` `!中` `!低`（`!!!` = 高、`!!` = 中）
  - 言葉はスペースで区切ってください
- **優先度**（高・中・低）でチェック欄の色が変わり、優先度の高い順に並ぶ
- **サブタスク**（チェックリスト）と **メモ**
- **リマインド**: 期限の◯分前に通知。アプリのアイコンに今日のタスク数のバッジ
- **📅 カレンダーに登録**: アラーム付きの予定として端末のカレンダーに追加
- **同期**: GitHub の Gist を使ってスマホとPCで同じタスクを見られる（オフラインでも使え、つながったら自動で同期）
- 完了・削除の「元に戻す」、データの書き出し・読み込み、ダークモード

## 同期のしくみと注意

- タスクは自分の GitHub アカウントの **secret Gist**（`yarukoto-tasks.json`）に保存されます。
  secret Gist は一覧や検索には出ませんが、**URL を知っている人は閲覧できます**。パスワードなど見られて困る情報は書かないでください。
- トークンは各端末のブラウザの中だけに保存されます。権限は **gist だけ** のトークンを使ってください。
- 2台で同じタスクを同時に編集した場合は、後から編集した方が残ります（別々のタスクの変更はどちらも残ります）。

## リマインドの注意

サーバーを持たない作りのため、通知が出るのは **アプリを開いている間（またはバックグラウンドで動いている間）** です。
アプリを閉じていても確実に知らせてほしいタスクは「📅 カレンダーに登録」を使ってください。
iPhone では、ホーム画面に追加したアプリでのみ通知を使えます。

## 開発

```sh
python3 -m http.server 8770   # http://localhost:8770
```

ファイルを変更したら `sw.js` の `VERSION` を上げてから push してください。

- `index.html` … 画面
- `style.css` … 見た目
- `dates.js` … 日付の処理・クイック追加の解析
- `store.js` … 保存と Gist 同期
- `app.js` … 画面の動き・リマインド・設定
- `sw.js` / `manifest.webmanifest` / `icons/` … PWA
